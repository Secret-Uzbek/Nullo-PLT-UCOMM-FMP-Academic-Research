## Layer role

This repository should function as the academic bridge layer between:

- the central public hub;
- the theoretical branch;
- publication-facing materials;
- deeper research archives and datasets.

It should not remain a broken auto-generated surface with mojibake and weak
service files.

It should also not collapse raw archive memory, publication bundles, and theory
entry surfaces into one unreadable block.

## Human reading path

If you are a human reader, start with:

1. this `README.md`
2. `CITATION.cff`
3. root academic bridge materials
4. linked central and theory repositories
5. publication-facing and donor repositories when needed

## Ecosystem position

This repository belongs to the wider FMP/Terra contour:

- `FMP-CENTRAL-REPO` — central public hub
- `Theory-of-fractal-metascience-paradigm` — theory branch
- `terra-legal` — donor legal/governance layer
- `AIUZ-terra-codex-FMP` — FMP package and publication bridge

## Layer boundaries

Keep here:

- NULLO, PLT, UCOMM, and FMP bridge research;
- academic bridge texts and datasets;
- release and citation surfaces for this bridge layer.

Do not overload this repository with:

- generic archive debris;
- donor governance duplication;
- machine traces as first public entry;
- practice implementation files without bridge role.
