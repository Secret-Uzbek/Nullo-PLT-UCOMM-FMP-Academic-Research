## Rule

If a work already has a DOI in ORCID or Zenodo, this repository should not create a second Zenodo record for the same work. The correct action is to:

1. store the source package in GitHub;
2. attach the existing DOI in README / CITATION / `.zenodo.json` metadata;
3. only create a new Zenodo upload when the title is genuinely unpublished or the upload is an intentionally new version of an existing Zenodo concept DOI.
